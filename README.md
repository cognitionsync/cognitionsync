# CognitionSync

Marketing site for CognitionSync — an applied-AI studio. Built with React, Vite, TypeScript,
Tailwind CSS, and framer-motion.

## Local development

```bash
npm install
npm run dev      # http://localhost:5173
```

## Production build

```bash
npm run build    # outputs to client/dist
```
